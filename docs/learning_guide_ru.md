# Научная защита: причинный soft sensor

Вопрос: улучшает ли нейросетевой прогноз и объединение с механистической моделью оценку будущего состояния, когда в каждый момент измеряется только одна из шести стадий? `benchmark.py` реализует весь путь: `simulate` → `replay` → `windows` → `SensorGRU` → `fuse_weights` → `metrics`.

## Что значит причинность

Здесь «причинный» означает доступность информации во времени: прогноз в момент t использует только наблюдения до t включительно. Это не установление причинного эффекта вмешательства в смысле causal inference. В момент t текущий датчик уже доступен. Прогноз управляющего сигнала использует последнее известное значение, а не истинные будущие значения.

`test_prefix_invariance` меняет все будущие измерения и управление и проверяет неизменность уже рассчитанных признаков и прогнозов. Временно близкие окна зависимы, поэтому разделение проводится целыми экспериментальными прогонами. Среднее и стандартное отклонение нормализации вычисляются только на train.

## Обучение GRU

GRU имеет 32 скрытых состояния и четыре группы выходов по шесть стадий. Целевая функция — masked MSE: L = Σ m(t,h,j)(ŷ(t,h,j)−y(t+h,j))² / Σm. Из-за вращающегося датчика в каждой паре время/горизонт наблюдается одна стадия. Ненаблюдаемые значения не превращаются в ложные нули: они исключены маской.

Градиенты меняют параметры GRU и выходного линейного слоя через AdamW. Симулятор и механистическая модель не обучаются. Лучшая эпоха выбирается по validation; test не участвует в выборе. Сохранённый checkpoint заново загружается перед оценкой. Latent RMSE доступна только потому, что это симуляция; основной показатель использует наблюдаемые зашумлённые цели.

## Почему не достаточно независимых дисперсий

Пусть ошибки физического и нейросетевого прогноза ep и en. Для смеси ŷ=(1−w)ŷp+wŷn минимизация среднего квадрата ошибки даёт

w = (E[ep²]−E[ep en]) / (E[ep²]+E[en²]−2E[ep en]).

Используются вторые моменты, учитывающие смещение, а не только центрированные дисперсии. Независимый comparator полагает перекрёстный момент нулём. В реальности обе модели видят общие датчики и ошибаются согласованно. Вес ограничен [0,1] и оценивается отдельно для горизонта только на validation. Ограничение стабилизирует смесь, но может отрезать оптимальную экстраполяцию.

## Наблюдаемый результат

На обычном синтетическом тесте при горизонте 12 RMSE: persistence 0.0520, physics 0.0379, GRU 0.0344, correlated fusion 0.0339. Это средние трёх запусков; отдельные значения сохранены. При изменении кинетики RMSE смеси увеличивается до 0.0536. Эти числа нельзя выдавать за точность на реальном CO₂-производстве.

Интервалы ошибки строятся по validation residuals, а интервалы разности методов — bootstrap целых test-прогонов. Это восемь кластеров; неопределённость велика. Три seeds обучения не создают новые независимые установки или новые процессные траектории. В отчёте сохраняются и случаи, где более сложный метод хуже.

## Главное ограничение

Симулятор близок по структуре механистической модели. Это полезно для тестирования инженерной корректности, но создаёт благоприятный мир для физического prior. Требуется дальнейшая проверка при структурно другой динамике и на разрешённых реальных данных. Старый индекс prior[t+h] сам по себе не доказывает утечку: нужно установить, когда prior был рассчитан и доступен.

Упражнение: измените только коэффициент кинетики в новом OOD-наборе и сравните ошибки и покрытие интервалов без повторного подбора весов. Отдельным экспериментом измерьте влияние длины окна, заранее зафиксировав выбранные значения.
